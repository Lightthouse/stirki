  Деплой

  - Dockerfile.backend — Python 3.12 + uv
  - frontend/Dockerfile — Node 20 + build
  - Caddyfile — reverse proxy + SPA fallback + автоматический HTTPS
  - compose.yml — обновлён: добавлены backend, frontend, caddy

  Для запуска:

  # Backend (dev)
  uv run uvicorn src.api.app:app --reload

  # Frontend (нужен Node.js)
  cd frontend && npm install && npm run dev

  # Полный стек (продакшн)
  docker compose up -d

  Важно: для работы frontend нужно установить Node.js. Для YooKassa заполните YOOKASSA_SHOP_ID и YOOKASSA_SECRET_KEY в .env.
