 План миграции Stirki ON: Telegram бот → PWA

 Контекст

 Сервис доставки стирки "Стирки ON" работает как Telegram-бот (polling). Из-за технических ограничений переходим на PWA-приложение. Telegram-бот больше не используется.

 Решения:
 - Frontend: React + TypeScript + Vite (PWA)
 - Backend: FastAPI
 - ORM: SQLAlchemy async (вместо Tortoise)
 - Платежи: ЮKassa с поддержкой СБП
 - Kaiten интеграция — остаётся

 Фаза 4: Интеграция ЮKassa + СБП

 Поток оплаты:

 1. Клиент подтверждает заказ → POST /api/orders
 2. Backend создаёт заказ + вызывает Payment.create() с payment_method_data: {type: "sbp"}
 3. Backend возвращает confirmation_url
 4. Frontend редиректит на страницу оплаты ЮKassa (СБП QR / ссылка в банк-приложение)
 5. После оплаты — редирект обратно в PWA на /orders/{id}
 6. ЮKassa шлёт webhook → backend обновляет payment_status и order_status

 Маппинг статусов:

 ┌───────────┬────────────────┬─────────────────────┐
 │  ЮKassa   │ payment_status │    order_status     │
 ├───────────┼────────────────┼─────────────────────┤
 │ pending   │ pending        │ waiting_for_capture │
 ├───────────┼────────────────┼─────────────────────┤
 │ succeeded │ succeeded      │ new                 │
 ├───────────┼────────────────┼─────────────────────┤
 │ canceled  │ canceled       │ canceled            │
 └───────────┴────────────────┴─────────────────────┘
