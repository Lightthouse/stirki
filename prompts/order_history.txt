 План: Иконки PWA, симуляция оплаты, страница истории заказов

 Контекст

 Проект PWA нуждается в трёх доработках:
 1. Иконки PWA отсутствуют — манифест ссылается на icon-192.png и icon-512.png, но файлов нет
 2. Нет возможности локально протестировать оплату — заказ застревает в WAITING_FOR_CAPTURE
 3. Нет страницы истории заказов — бэкенд (GET /orders) готов, фронтенд отсутствует

 ---
 Часть 1: Иконки PWA

 Конвертировать ~/stirki_logo.jpg в два PNG-файла с помощью ImageMagick:
 - frontend/public/icons/icon-192.png (192×192)
 - frontend/public/icons/icon-512.png (512×512)

 Команды:
 convert ~/stirki_logo.jpg -resize 192x192 frontend/public/icons/icon-192.png
 convert ~/stirki_logo.jpg -resize 512x512 frontend/public/icons/icon-512.png

 Манифест в frontend/vite.config.ts уже настроен на эти пути — изменений в коде не нужно.

 ---
 Часть 2: Симуляция оплаты (dev-only)

 2a. Бэкенд: dev-эндпоинт

 Файл: src/api/routers/payments.py

 Добавить эндпоинт POST /api/payments/test/simulate/{order_id}:
 - Доступен только если APP_ENV != production (проверять через AppSettings)
 - Вызывает order_repo.update_status(order, NEW, SUCCEEDED, changed_by="test")
 - Возвращает {"status": "ok", "order_id": ...}

 2b. Фронтенд: кнопка «Симулировать оплату»

 Файл: frontend/src/components/steps/StatusStep.tsx

 Когда статус заказа waiting_for_capture:
 - Показать кнопку «Симулировать оплату (dev)»
 - По клику вызвать POST /api/payments/test/simulate/{orderId}
 - После успеха — поллинг подхватит новый статус NEW

 Файл: frontend/src/api/index.ts — добавить функцию simulatePayment(orderId: number)

 ---
 Часть 3: Страница истории заказов

 3a. Установить React Router

 cd frontend && npm install react-router-dom

 3b. Настроить маршрутизацию

 Файл: frontend/src/App.tsx

 Обернуть в BrowserRouter, добавить маршруты:
 - / → OrderPage (существующий флоу создания заказа)
 - /orders → OrdersPage (новая страница истории)

 3c. Создать страницу истории

 Файл: frontend/src/pages/OrdersPage.tsx (новый)

 - Загружает список заказов через getOrders() (функция уже есть в frontend/src/api/index.ts:40)
 - Использует тип OrderListItem (уже есть в frontend/src/types/index.ts:70)
 - Список карточек заказов: номер, дата, статус (русское название), цена
 - Активные заказы (не delivered/canceled) подсвечены цветом/бейджем
 - Клик по заказу → показать детали (через GET /orders/{id})
 - Кнопка «Новый заказ» → переход на /

 3d. Навигация

 Добавить ссылку на /orders в интерфейс — кнопка/ссылка «Мои заказы» на главной (после авторизации) и на шаге StatusStep.

 3e. Маппинг статусов на русские названия

 Файл: frontend/src/utils/statusNames.ts (новый)

 Верификация

 1. Иконки: ls frontend/public/icons/ — два файла, проверить размеры
 2. Симуляция оплаты: создать заказ → на шаге статуса нажать «Симулировать оплату» → статус меняется на «Новый»
 3. История заказов: перейти на /orders → видны все заказы, активные подсвечены, клик раскрывает детали
