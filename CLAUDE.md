# CLAUDE.md

Инструкции для Claude Code. Подробное описание проекта — в `README.md`, открытые задачи — в `docs/TODO.md`.
Начинай с них и сверяй описание с кодом.

## Правила

- **Язык проекта — русский**: пользовательские тексты, комментарии, коммиты, документация. Имена в коде — английские.
- Бюджет проекта маленький — выбирай простые решения без новой инфраструктуры и лишних зависимостей.
- Новое знание о проекте записывай в `README.md` (как устроено) или `docs/TODO.md` (что не сделано). Новые md-файлы не заводить.
- Схема и начальные данные БД — только в `pg_init/01-schema.sql`, миграций нет: реальных клиентов пока нет, БД пересоздаётся (README, «База данных»).
- Цены и условия тарифов дублируются в оферте (`docs/оферта.txt` и `frontend/src/components/ui/OfferModal.tsx`) — при их изменении править оба.
- Время бизнеса — московское (`src/services/schedule.py`, фиксированный UTC+3).

## Команды

```bash
./run.sh local                 # БД в Docker, backend :8001 и frontend :5173 с hot-reload
uv run ruff check src/         # линтер бэкенда
cd frontend && npx tsc -b      # проверка типов фронтенда
cd frontend && npm run build   # сборка фронтенда
```
